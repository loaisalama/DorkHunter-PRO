# DorkHunter PRO — Android Native (النسخة الأولى)

تطبيق Android أصلي مبني بـ Kotlin وJetpack Compose.

## الوظائف الحالية
- منشئ استعلامات Google Dorks أساسي.
- تقييد اختياري للنطاق الذي تملك صلاحية فحصه.
- كلمات مفتاحية وعبارة دقيقة واستبعاد كلمات.
- البحث في عنوان الصفحة أو مسار الرابط أو نص الصفحة.
- أنواع مستندات عامة منشورة: PDF وDOCX وXLSX وCSV وPPTX وTXT.
- فتح البحث في Google وDuckDuckGo وBing وStartpage.
- حفظ الاستعلامات وسجل آخر عمليات البحث محلياً على الجهاز.

## البناء
1. فك ضغط المشروع.
2. افتح مجلد `DorkHunterPRO-Android` في Android Studio.
3. استخدم JDK 17، ثم نفّذ Gradle Sync.
4. شغّل التطبيق على هاتف Android أو أنشئ APK من Build > Build APK(s).
